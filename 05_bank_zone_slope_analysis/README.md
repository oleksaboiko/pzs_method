# 2. Визначення ухилів рельєфу берегових зон за допомогою растрової алгебри

> Кут ухилу рельєфу визначається як тангенс пропорції різниці висоти растру в точці, перпендикулярній до лінії берегу та висоти берегу в точці, до якої проведено перпендикуляр, поділена на нормативну відстань між точками (стандартну ширину ПЗС).
>
> Маючи інформацію про кут ухилу в стандартній ширині ПЗС та ідентифікатор точки водного об'єкту, з якої цей ухил розрахований, можна визначити для кожної точки водного об'єкту (і відповідно території навколо об'єктів), чи потрібно продовжувати відстань далі, до нормативно визначеної дистанції.
>
> На основі такої інформації можливо сформувати растрове покриття ПЗС водних об'єктів, придатне для подальшого використання.
