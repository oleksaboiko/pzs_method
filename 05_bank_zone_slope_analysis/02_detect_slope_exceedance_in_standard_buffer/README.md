# 2.2. Розрахунок растру понаднормативних ухилів `#slope_detected_in_buffer_25`

Зазначені тимчасові інформаційні растри використовуються для розрахунку растру кута ухилів рельєфу із понаднормативними значеннями на нормативній відстані (в буфері), де значимі пікселі містять:

- `1` у випадку перевищення значення допустимого ухилу;
- `0` у випадку нормативного значення ухилу.

Незначимі пікселі - *NAN*.

```yaml
IF(((#dem_in_buffer_25_raster - #nearest_water_pix_elev_raster_in_buffer_25) / #distance_in_buffer_25_raster ) > 0.05240778, 1, 0 )
```

> `0.05240778` - тангенс нормативно визначеного кута в `3°`.
