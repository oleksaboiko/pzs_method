# Одиниці виміру

Тут чому обираємо одиниці - відповідно до задач і географічного масштабу дослідження:

- якщо масштаб ненормативний, то застосовуються для ознайомчих задач;
- якщо масштаб нормативний (в масштабі топозйомки), то для задач нормативних процесів управління територіями відповідного масштабу (комплексний/детальний плани)
