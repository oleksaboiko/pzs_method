# 1.1. Перелік постійних робочих даних

- Одноканальний растр водних об'єктів `#water_px_id_raster`, що для значимих пікселів містить унікальний ідентифікатор пікселя в екстенті AOI, а для незначимих - *NAN або 0*;
- Одноканальний растр висоти водних об'єктів `#water_px_elev_raster`, що для значимих пікселів містить значення висоти пікселя, взяте з DEM, в одиницях виміру, які співпадають з одиницями виміру AOI, а для незначимих - *NAN або 0*;
- Одноканальний растр, що містить значення відстані пікселя до найближчого пікселя водного об'єкту, в одиницях виміру, які співпадають з одиницями виміру AOI `#distance_raster`;
- Одноканальний растр `#nearest_water_pix_id_raster`, що містить значення ідентифікатора найближчого пікселя водного об'єкту;
- Одноканальний растр `#nearest_water_pix_elev_raster`, що містить значення висоти найближчого пікселя водного об'єкту, взяте з DEM, в одиницях виміру, які співпадають з одиницями виміру AOI;
- Векторний шар центроїдів пікселів для водних об'єктів `#water_px_id_vector`, що містить атрибут із унікальним ідентифікатором пікселя для кожного центроїда. Нумерація ID має починатись із 1.
