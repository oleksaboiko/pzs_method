# 1. Підготовка і формування постійних робочих даних

**Мета етапу** - підготувати набори даних у форматі, придатному для подальшого аналізу інструментами растрової алгебри.

## Ключові характеристики робочих даних

```markdown
a) растровий формат, із розміром пікселя, що дорівнює розміру пікселя DEM;
b) Екстент всіх растрів дорівнює екстенту AOI.
```
