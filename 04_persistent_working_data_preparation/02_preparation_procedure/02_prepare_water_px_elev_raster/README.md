# 1.2.2. Підготовка растру висоти водних об'єктів `#water_px_elev_raster`

За допомогою растрової алгебри присвоюємо пікселям растру водних об'єктів, що мають `ID > 0`, значення висоти із відповідних пікселів DEM.

Приклад псевдокоду:

```yaml
( #water_px_id_raster > 0 ) * DEM
```

![Water elevation raster](image_1771530448248_0.png)

> **Результат** - одноканальний растр водних об'єктів `#water_px_elev_raster`, зберігаємо в постійну пам'ять комп'ютера.
