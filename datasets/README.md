# Datasets

Ця тека описує, які дані потрібні для практичного запуску методики.

## Що потрібно для роботи

- архів тестового датасету, згаданий у робочому описі як `dataset_2.zip`;
- цифрова модель рельєфу (ЦМР);
- векторні дані водних об'єктів;
- окремий файл проєкту QGIS, збережений у тій самій теці, що і датасет.

## Підготовка робочої теки

1. Завантажити архів тестового датасету.
2. Розархівувати його в окрему робочу теку.
3. Створити новий QGIS-проєкт.
4. Додати в нього ЦМР і вектори водних об'єктів.
5. Зберегти проєкт у тій самій теці, де розміщено датасет.
