# Зауваження

- В інструкції мова йде про `NAN`, але формули застосовуються на `0`.
- На великому растрі цей алгоритм дуже довго працює. Тому можливо швидше через калькулятор растрів, хоча будуть доп. кроки, щось типу:

```text
IF(
  "nearest_water_pix_id_raster_in_50_m@1" =
  "problem_water_id_raster@1",
  "nearest_water_pix_id_raster_in_50_m@1",
  NULL
)
```

- Принаймні для великих обсягів та не потужних компів.
