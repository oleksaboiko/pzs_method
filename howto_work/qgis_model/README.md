# QGIS Model

У цій теці збережено QGIS Processing Model, який згадується у робочому описі.

## Файл

- `model_pzs.model3`

## Призначення

Модель призначена для тестового запуску методики в автоматизованому режимі в середовищі QGIS.

За структурою файлу видно, що модель використовує стандартні алгоритми QGIS/GRASS/GDAL, зокрема побудову растрових похідних та перетворення векторних і растрових даних.
